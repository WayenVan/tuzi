# Roadmap

## Neovim integration

- Ship an official Neovim plugin.
- Support sidebar, floating-window, and terminal layouts.
- Synchronize the current buffer and Tuzi cursor.
- Manage Tuzi startup and restore sessions per workspace.

## Deeper tree workflows

- Show Git status and editor diagnostics on tree nodes.
- Add bookmarks and workspace roots.
- Support configurable ignore rules and batch rename.
- Add a contextual action palette.
